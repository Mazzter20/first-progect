# Гра для пари 18+

Веб-гра для двох у стилі «Couples Games: Spicy Challenge». Працює в браузері телефона, без встановлення.

## Ігри (15+)

- 🎭 **Правда чи дія** — питання та завдання з таймером, рахунок очок, нова колода.
- 🧠 **Квіз для пари** — вгадай відповідь партнера.
- 🙈 **Я ніколи не…** — зізнання, рахунок «вже робили».
- ⚖️ **Що б ти обрав(ла)?** — оберіть варіант по черзі та перевірте сумісність.
- 🎲 **Кубики пристрасті** — випадкова дія + місце + час.
- 🎡 **Колесо** — крути й виконуй (до 12 секторів за раз з великої колоди).
- 👆 **Рулетка дотику** — обоє кладуть палець на екран, гра обирає одного.
- 💆 **Релакс-масаж** — покрокова програма з таймером і спокійним звуком.
- 📳 **Вібромасажер** — сила й ритм. **Лише Chrome на Android** (на iPhone не працює — обмеження системи).
- 📈 **Ескалація** — правда чи дія, де рівень сам росте від 💗 до 😈.
- 💣 **Гаряча бомба** — відповідай і передавай телефон; у кого вибухне, той отримує фант.
- 👕 **Роздягання** — відмова від завдання коштує речі одягу.
- 🔥 **Пози** — 36 поз зі схемами А/Б, описом, порадами, обраним і «спробували».
- 🕯️ **Розмови по душах** — 30 питань у трьох етапах і фінальна вправа «4 хвилини в очі».
- ✍️ **Мої картки** — власні питання й завдання (заголовки «ПРАВДА», «ДІЯ», «Я НІКОЛИ НЕ», «КВІЗ»).
- 🃏 **Бажання** — кожен окремо «так / можливо / ні», показуються лише збіги.
- 🕹️ **Міні-ігри**: 🏒 аерохокей, 🦛 щасливі бегемоти, ⚡ хто швидший, 🪢 перетягування, 🎨 малюй і вгадуй.

## Рівні

| Рівень | Зміст |
|--------|--------|
| 💗 Романтика | ніжність, спогади, легкі дії |
| 🔥 Флірт | натяки, поцілунки, тілесний флірт |
| 🌶️ Пристрасть | прелюдія, фантазії, більше тіла |
| 😈 Шалено | найвідвертіше; перед входом — екран зі **стоп-словом** і згодою |

Після квізу та міні-ігор той, хто програв, отримує **фант**: випадковий із гри, власне бажання або без фанту.

## Запуск

Відкрийте `index.html` у браузері або увімкніть GitHub Pages (Settings → Pages → гілка `main`, папка `/`).

## Свої картки

Текст у `js/data.js` або прямо в грі («Мої картки»). `{p}` — ім’я партнера, `{me}` — чий хід.

Особисті картки можна тримати в `js/my-cards.js` (формат як у `js/data.js`, наприклад `DATA.truth.wild.push(...)`). Файл підключається після `data.js`, не потрапляє в git (див. `.gitignore`), а без нього гра просто працює зі стандартними картками.

Закінчення в дужках («зробив(ла)», «готовий(а)») і займенники («він/вона», «його(її)») підставляються за статтю гравців. За замовчуванням — того, чий хід; якщо безпосередньо перед словом згадано `{p}` чи «він/вона» — партнера.

## Безпека

Гра лише для дорослих 18+. Будь-яке завдання можна пропустити. На рівні «Шалено» обов’язкове стоп-слово: після нього все зупиняється без питань.
