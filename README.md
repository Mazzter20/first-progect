# Гра для пари 18+

Веб-гра для двох у стилі «Couples Games: Spicy Challenge». Працює в браузері телефона, без встановлення.

## Ігри

- 🎭 **Правда чи дія** — питання та завдання з таймером, рахунок очок.
- 🧠 **Квіз для пари** — вгадай відповідь партнера.
- 🙈 **Я ніколи не…** — зізнання, рахунок «вже робили».
- ⚖️ **Що б ти обрав(ла)?** — оберіть варіант по черзі та перевірте сумісність.
- 🎲 **Кубики пристрасті** — випадкова дія + місце + час.
- 🎡 **Колесо** — крути й виконуй завдання.
- 👆 **Рулетка дотику** — обоє кладуть палець на екран, гра обирає одного.
- 💆 **Релакс-масаж** — покрокова програма з таймером і спокійним звуком.
- 📳 **Вібромасажер** — сила, ритм (постійно, пульс, хвиля, серцебиття), швидкість і блокування екрана. Працює лише в Chrome на Android, відкритому як звичайний сайт.
- 📈 **Ескалація** — правда чи дія, де рівень сам росте від 💗 до 😈.
- 💣 **Гаряча бомба** — відповідай і передавай телефон; у кого вибухне, той отримує фант.
- 👕 **Роздягання** — відмова від завдання коштує речі одягу.
- 🔥 **Пози** — 24 пози зі схематичними малюнками, описом, порадами, складністю, обраним і відмітками «спробували».
- 🕯️ **Розмови по душах** — 30 питань у трьох етапах і фінальна вправа «4 хвилини в очі».
- ✍️ **Мої картки** — додавайте власні питання й завдання прямо в грі, по одній або цілим списком.
- 🃏 **Бажання** — кожен окремо відповідає «так / можливо / ні», показуються лише збіги.
- 🕹️ **Міні-ігри** на одному телефоні: 🏒 аерохокей, 🦛 щасливі бегемоти, ⚡ хто швидший, 🪢 перетягування, 🎨 малюй і вгадуй.

Чотири рівні: 💗 Романтика, 🔥 Флірт, 🌶️ Пристрасть, 😈 Шалено.

Після квізу та міні-ігор той, хто програв, отримує **фант**: переможець обирає випадковий фант із гри або загадує власне бажання.

## Запуск

Відкрийте `index.html` у браузері або увімкніть GitHub Pages (Settings → Pages → гілка `main`, папка `/`).

## Як додати свої картки

Весь текст лежить у `js/data.js`. `{p}` у тексті замінюється на ім’я партнера.
